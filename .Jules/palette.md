# Palette's Journal - FocusCube

## 2025-05-18 - Task-specific accessibility context for interactive lists
**Learning:** Generic icon button content descriptions like "Drag Handle" or "Toggle Complete" in list items leave screen reader users without context as to which item is being manipulated.
**Action:** Always include item title/context in accessibility content descriptions for item-level actions (e.g., "Reorder task: [title]" or "Mark [title] as complete").
