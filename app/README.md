# FocusCube 🧊

FocusCube is a comprehensive productivity and academic tracking Android application built with Kotlin and Jetpack Compose. It's designed to help you stay focused, build positive habits, track your academic progress, and connect with a community for accountability.

## ✨ Features

*   **Focus Timer & Work Sessions:** Deep work and Pomodoro timer modes to maximize productivity.
*   **Focus Shield (App Blocker):** Block distracting apps during your focus sessions.
*   **Habit Tracker:** Build and maintain positive habits with streak tracking and visual progress.
*   **Academic Suite:** Manage your timetable, track subjects, and organize academic tasks.
*   **Community Groups:** Join accountability groups, set shared goals, and compete on leaderboards.
*   **Analytics & Stats:** Detailed insights into your focus time, completed habits, and overall productivity.
*   **Journal & Reading Log:** Keep track of your mood, gratitude, and reading progress.
*   **Voice Notes & AI Chat:** Quickly capture thoughts and interact with AI for academic or productivity assistance.

## 🛠️ Tech Stack

*   **Language:** [Kotlin](https://kotlinlang.org/)
*   **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose) - Modern, declarative UI.
*   **Architecture:** MVVM (Model-View-ViewModel).
*   **Local Storage:** [Room Database](https://developer.android.com/training/data-storage/room) for robust local persistence.
*   **Asynchronous Programming:** Kotlin Coroutines & Flow.

## 🚀 Getting Started

### Prerequisites

*   Android Studio (latest recommended)
*   JDK 17+

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/yourusername/FocusCube.git
    ```
2.  Open the project in **Android Studio**.
3.  Sync the Gradle project to download all necessary dependencies.
4.  Build and run the app on an emulator or physical device.
